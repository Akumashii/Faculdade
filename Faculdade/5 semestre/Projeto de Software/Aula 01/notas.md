## Relembrar

#### Engenharia de Software

Software, por definição é:
- conjunto de instruções
- utilização de dados
- documentação
- produto
  - não material
  - desgaste único 
  - fabricação (sem materia-prima)
 
#### Metodologia

As etapas de metodologia de um produto seguem:
- Comunicação - Requisitos de Software
  - └> Planejamento - Custo, Tempo, Protótipo 
    - └> Projeto - UML
      - └> Construção - Código, Testes de Sistema
        - └> Entrega - Documentação, Manutenção, Testes de Aceitação
