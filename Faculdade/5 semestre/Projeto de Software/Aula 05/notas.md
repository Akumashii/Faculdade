## Feature Driven Development (FDD)
É o desenvolvimento dirigido a funcionalidade

Criado pelo mesmo grupo da UML. Descrevem como um processo ágil adaptativo que pode ser aplicado a projetos de software de porte moderado e a projetos maiores

Etapas:
1) Desenvolver o modelo geral

   	- Modelo de Caso de Uso
   	- Diagrama de Domínio
	  - Imagem Ilustrativa
