# Sistema de Arquivos

armazenamento de dados e programas, diretórios possibilitam a organização de arquivos  
envolve mecanismos para armazenamento e acesso, cria recursos lõgicos a partir de recursos físicos, armazena metadados em programas, informação está no disco rígido salva

visão do usuário:
- operação sobre os arquivos
- permissões de acesso
- organização dos arquivos em diretórios
- backup e recuperação

visão do sistema operacional:
- localicação dos arquivos, nos diretórios e suas prpriedades
- gerência de espaço livre no dispositivos de armazenamento

disco fragmentado, espaço livre entre arquivos insuficiente para armazenar um grande arquivo, gerencia de espaços livres

Arquivo aberto possui:
- ponteiro do arquivo, exclusivo
- ...
