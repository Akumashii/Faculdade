# Sistema Multiagentes

Multiagente = sociedade = comunidade = times = equipes.  
Com foco em agente

\

Classe -> Objeto   
- atributos
- serviços = métodos

Categoria -> Agente
- fatos/crenças (tal como vimos em prolog)
- regras/planos

\

Classes são invocadas, enquanto Categorias são evento-ativador (trigger). Assim Agentes são disparados quando necessitam, percebem o contexto e reagem a ele.  
Em si, Agente e Objetos são semelhante, contudo Objetos não são autônomos e funcionam por ordem explícita. 

Podemos trabalhar Agentes com Orientação a Objetos, contudo, nesta disciplina estaremos trabalhando com PROLOG.

REATIVOS

- atuam

Paradigma Mental desses Agentes (BDI):
- belief == crença/fato
- disere == plano em tese/teoria/latente
	- para a mesma situação vários planos
- intention == plano em execução
	- 1° ativado via evento
	- 2° contexto

\

belief = sensor  
disere = planejamento
