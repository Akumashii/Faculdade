# Métodos de Agentes de IA

Lembrando que, Sistema de Comportamente Inteligente:
- base de conhecimento
- motor de raciocícnio
- aprendizado de máquina

um sistema de comportamente inteligente pode ser um Agente
- hardware ou robo
- software ou bot

Um Sistema MultiAgente precisa:
- Autonomia
- Proatividade(iniciativa)
- Adaptação(se atualizar por novos parâmetros)
- Comunicação ou Habilidade Social

É o sistema teórico mais completo possível

---

Sistema Multiagentes - foca no dividir para conquistar
- área de Ia conhecida com IA Distribuída, inspirada nas organizações/comunidades de insetos (swarm intelligence) como, por exemplo, o comportamente das formigas de um formigueiro
- dentro da computação de um agente ele pode serÇ
	- uma entidade de hardware
 	- uma entidade de software, distribuidos geograficamente (técnicas de comunicação de dados - sockets, multicast, ...)

 ---

Aplicação de Sistemas Multiagentes == EQUIPES/TIMEs
- Sistemas Persvasivos/Ubíquos -> automação residencial e industrial
- Características:
1) Autonomia - threads
2) Proatividade - threads + if
3) Adaptação/Flexibilidade
4) Habilidade Social == Comunicação (comando/ordem; consulta; plantio de crença)
	- socket
 	- diretivas de comunicação (.broadcast; .tell; .send)

---

Há inumeras arquiteturas
- Imperativa -> O.O. e programação procedural -> é dito oque fazer, como fazer e quando fazer
- BDI -> Belief, Desire and Intention
	- Interpretador JASON para a linguagem AgenteSpeak(L) (baseada no Prolog)
 	- belief = crença == fato
	- disere = desejo == plano em tese/teoria/latente
	- intention = intenção == plano em execução
